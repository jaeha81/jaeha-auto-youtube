# Project Overview

## 채널 정체성
- 이름: 프로슈테크 빌더 (Prosu-Tech Builder)
- 포지션: AI 비개발자 출신이 AI 성장 과정을 공개하는 교육형 유튜버
- 핵심 메시지: "나는 AI를 가르치는 사람이 아니다. AI와 함께 성장하는 과정을 직접 증명하는 사람이다."

## 프로젝트 목적
비개발자 AI 성장 기록을 히스토리 영상 시리즈로 제작·업로드하고,
Bucky 에이전트와 연동하여 장기 운영 가능한 유튜브 자동화 시스템 구축

## 핵심 시청자 (페르소나)
- AI를 배우고 싶지만 개발자가 아니라 두려움을 느끼는 직장인
- 자동화/AI 도구를 실무에 써보고 싶은 비전공자
- AI 시대에 자기 분야를 혁신하고 싶은 현장 전문가

## 콘텐츠 축 (4단계)
- 1단계 AI 성장기: 입문, 시행착오, 실패, 실제 학습 과정
- 2단계 에이전트 구축기: GPT/Claude/Gemini/Codex/Obsidian 실제 구축 공개
- 3단계 사업 적용기: 인테리어 자동화, 콘텐츠 자동화, 수익화 실험
- 4단계 미래 실험실: AI 에이전트 네트워크, 디지털 기업, 미래 직업 실험

## 운영 원칙
- 성공도 공개, 실패도 공개, 수정도 공개
- 결과보다 과정 중심
- AI는 보조 도구, 사람의 진정성이 중심
- 사용자 승인 없이 자동 업로드 금지
- Make.com / n8n 사용 금지
