## 2026-06-10

### 에이전트 주행(Autopilot) 범위: 업로드 직전까지만
- 결정: autopilot은 동기화→스크립트→SEO→썸네일 브리프까지만 자동 실행, 업로드는 기존 승인 플로우 유지
- 사유: "사용자 승인 없이 자동 업로드 금지" 원칙 유지 — 에이전트가 준비하고 사람이 발행

### 콘텐츠 방향 결정: Strategy Agent (Analytics 피드백 루프)
- 결정: 성과 리포트 + 발행 기록 + 미처리 노트를 분석해 다음 에피소드 주제를 제안하는 별도 에이전트 추가
- 사유: 에이전트 주행 인플루언서의 핵심은 "성과 → 다음 콘텐츠" 루프 자동화. 제안만 하고 선택은 사람이 함

### 썸네일: 텍스트 브리프만 생성
- 결정: Thumbnail Agent는 문구/구도/색상 브리프만 생성, 이미지 자동 생성은 하지 않음
- 사유: plan.md 차단 요소 준수 (MVP에서는 텍스트 브리프만)
