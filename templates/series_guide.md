# 시리즈 운영 가이드

## 콘텐츠 파이프라인 사이클

```
[성장기 노트 작성] → [스크립트 생성] → [SEO 생성] → [영상 촬영]
→ [편집] → [검토/승인] → [업로드] → [성과 분석] → [다음 에피소드 개선]
```

## 에피소드 노트 작성 기준

### 노트 파일 위치
- 직접 작성: content/source-notes/ep001.md
- Obsidian에서 동기화: agents/bucky_sync_agent.py 실행

### 노트 작성 양식
```markdown
# 에피소드 제목 아이디어

## 에피소드 번호
001

## 날짜/시기
2024년 X월 (대략적인 시기)

## 핵심 사건
무슨 일이 있었나? 한두 문장으로

## 상황/배경
그 당시 어떤 상태였나?

## 시도한 것
무엇을 해보려 했나?

## 실패 / 막힌 것
어디서 막혔나? 어떤 실수를 했나?

## 결론 / 배운 것
결국 어떻게 됐나?

## 다음 에피소드 연결
이 경험이 다음에 어떻게 이어졌나?
```

## 업로드 스케줄 권장
- 초반 (0~50명): 주 1~2회
- 성장기 (50~500명): 주 2회 고정
- 안정기 (500명+): 주 2~3회

## 영상 길이 권장
- 성장기 시리즈: 7~10분
- 튜토리얼 성격: 10~15분
- 짧은 인사이트: 3~5분
