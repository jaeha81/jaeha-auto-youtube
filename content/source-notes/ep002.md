# EP002 성장기 노트: 비개발자가 유튜브 자동화 시스템을 직접 만든 과정 전부 공개

작성일: 2026-06-10
태그: #youtube #성장기 #에이전트구축기

---

## 이 에피소드에서 하고 싶은 이야기

내가 유튜브를 하려고 마음먹었을 때, 처음엔 그냥 카메라 켜고 찍으면 되는 줄 알았다.
근데 찾아보니까 SEO도 해야 하고, 제목도 최적화해야 하고, 설명도 써야 하고, 태그도 달아야 하고…
이걸 다 수작업으로 하면서 동시에 콘텐츠 질까지 높인다? 내가 할 수 있을까 싶었다.

그래서 AI로 자동화하기로 했다. 그런데 나는 개발자가 아니다.

---

## 실제로 겪은 것들

### 처음 시도: "이미 만들어진 툴 쓰면 되지 않나?"
- Make.com, n8n, Zapier 다 찾아봤다
- 근데 유튜브 업로드 자동화는 대부분 API 제한이 걸리거나, 유료이거나, 너무 복잡했다
- 결국 "내가 직접 만들어야겠다"고 결론 냄

### Claude에게 물어보며 코드 짜기 — 처음엔 뭐가 뭔지 몰랐다
- Python이 뭔지도 제대로 몰랐는데, Claude 한테 "나 이런 거 만들고 싶다"고 설명했더니 코드를 짜줬다
- 그 코드를 붙여넣으면 에러가 나고, 에러를 또 붙여넣으면 고쳐줬다
- 이 과정을 수십 번 반복하면서 구조가 점점 잡혔다
- 느낀 것: 개발자 못 되어도 된다. 에러 메시지를 복붙할 줄 알면 된다

### 막혔던 가장 큰 지점: YouTube API
- OAuth 2.0이라는 게 있는데, 이게 대체 뭔지 몰랐다
- 구글 클라우드 콘솔 들어가는 것부터 겁이 났다
- 결국 Claude한테 "나 이거 처음인데 단계별로 알려줘"라고 했더니 설명해줬다
- 3시간 걸려서 credentials.json 발급받았다. 근데 그게 뭔지는 알게 됐다

### 자동화가 되는 순간
- python main.py generate --note ep001.md 쳤더니 스크립트가 생겼다
- SEO 파일도 자동으로 생겼다
- 그 순간 진짜 뭔가 넘어선 느낌이 들었다

## 지금 시스템 구조 (시청자에게 공개할 내용)
- Obsidian에 메모 → Python이 읽음 → Claude가 스크립트 생성 → SEO 자동 생성 → 대시보드에서 확인 후 승인하면 유튜브 업로드
- 이 영상도 이 시스템으로 만들어진 거다 (실제로 보여주기)
